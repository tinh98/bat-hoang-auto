⚡ Auto Bát Hoang

Một bookmarklet tự động 4 tính năng trên web-production-0893.up.railway.app. Script gọi thẳng API, dùng response để quyết định request kế tiếp và tự dừng khi hết lượt.

⚔️ Di TíchTự vào, chọn hướng, đánh quái/boss và CHIẾN TIẾP đến hết lượt.
🎣 Câu CáTự mua mồi khi hết rồi câu liên tục đến khi hết lượt câu.
🌾 Linh ĐiềnTự thu hoạch, tưới cây, trồng hạt và chờ cây chín để lặp lại.
👹 Boss Thế GiớiTự Khiêu Chiến khi hết hồi chiêu, dừng khi hết lượt hoặc boss bị hạ.
  1. Mở game, đăng nhập.
  2. Kéo nút bên dưới lên thanh bookmark, hoặc bấm Copy bookmarklet URL rồi tạo bookmark mới và dán URL.
  3. Bấm bookmark vừa tạo. Bảng điều khiển 4 tính năng hiện ở góc phải dưới.
  4. Bấm Chạy ở từng mục, hoặc mở Console gõ lệnh bên dưới. Dừng bằng stopAll().

Lệnh

auto()                 // Di Tích, API 150ms/request
autoCauCa()            // Câu Cá: mua mồi + câu
autoLinhDien()         // Linh Điền: thu hoạch, tưới, trồng
autoBoss()             // Boss Thế Giới: Khiêu Chiến
autoAll()              // bật cả 4 tính năng
stopAll()              // dừng tất cả
showAuto()             // mở lại bảng điều khiển

Tùy chỉnh

auto(50)                              // Di Tích nhanh hơn
auto({ maxRuns: 1 })                  // Di Tích 1 lượt
auto({ mode: 'dom' })                 // Di Tích fallback bấm nút
autoCauCa({ delay: 250, buyQty: 5 })  // tốc độ + số mồi mua mỗi lần
autoLinhDien({ checkInterval: 30000 }) // 30s kiểm tra Linh Điền/lần
autoLinhDien({ seedItemId: '...' })   // chỉ trồng một loại hạt
autoBoss({ delay: 500 })              // tốc độ Khiêu Chiến

Cơ chế

Mỗi tính năng chạy vòng lặp riêng, có thể bật song song. Di Tích dùng /combat/status, /combat/start, /combat/di-tich/choose, /combat/fight và dựa vào done / combat_revealed. Câu Cá dùng /cau-ca/status, /cau-ca/mua-moi, /cau-ca/cau. Linh Điền dùng /linh-dien và các API thu-hoach-tat-ca, tuoi, trong-tat-ca. Boss dùng /world-boss/status, /world-boss/my-status, /world-boss/attack.

Di Tích và Câu Cá dùng lượt riêng. Linh Điền tự chờ cây chín theo ready_at. Boss tự chờ cooldown_remaining và dừng khi hết lượt. Nếu server báo gửi quá nhanh, tăng delay trong lệnh tương ứng. Nếu bookmarklet bị CSP chặn, bấm Copy script rồi dán vào Console.
